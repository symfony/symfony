[Symfony][1] 是一个用于 Web 和控制台应用程序的 **PHP 框架**，以及一套
可重用的 **PHP 组件**。Symfony 被数千个 Web 应用程序和大多数
[流行的 PHP 项目][2]所使用。

安装
----

* 使用 Composer [安装 Symfony][4]（参见[需求详情][3]）。
* Symfony 严格遵循[语义版本控制][5]，发布"长期支持"（LTS）版本，
  并拥有可预测且对商业友好的[发布流程][6]。

赞助商
------

Symfony 7.3 由以下机构[支持][27]：
- [Les-Tilleuls.coop][29]

**Les-Tilleuls.coop** 是一个拥有 70 多名 Symfony 专家的团队，可以帮助您设计、开发和
修复项目。他们提供广泛的专业服务，包括开发、咨询、指导、培训和审计。
他们在 JS、Go 和 DevOps 方面也非常熟练。他们是一家工人合作社！

通过[赞助][28] Symfony 的开发来帮助 Symfony！

社区
