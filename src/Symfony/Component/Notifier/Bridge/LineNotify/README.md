LINE Notifier
=============

The LINE Notify bridge is deprecated as LINE Notify was shut down on 2025-03-31,
use the LineBot bridge instead.

DSN example
-----------

```
LINE_NOTIFY_DSN=linenotify://TOKEN@default
```
