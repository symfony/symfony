[Symfony][1] は、Web およびコンソールアプリケーション用の **PHP フレームワーク**であり、
再利用可能な **PHP コンポーネント**のセットです。Symfony は何千もの Web アプリケーションと
ほとんどの[人気のある PHP プロジェクト][2]で使用されています。

インストール
------------

* Composer で [Symfony をインストール][4]してください（[要件の詳細][3]を参照）。
* Symfony は[セマンティックバージョニング][5]を厳密に遵守し、「長期サポート」（LTS）
  バージョンを発行し、予測可能でビジネスフレンドリーな[リリースプロセス][6]を持っています。

スポンサー
----------

Symfony 7.3 は以下によって[サポート][27]されています：
- [Les-Tilleuls.coop][29]

**Les-Tilleuls.coop** は、プロジェクトの設計、開発、修正を支援できる 70 名以上の Symfony エキスパート
のチームです。開発、コンサルティング、コーチング、トレーニング、監査を含む幅広い
プロフェッショナルサービスを提供しています。また、JS、Go、DevOps にも高いスキルを持っています。
彼らは労働者協同組合です！

Symfony の開発を[スポンサー][28]して Symfony を支援してください！

ドキュメント
------------

* Symfony が初めての方は[入門ガイド][7]をお読みください。
* [Symfony デモアプリケーション][23]を試して、実践的に Symfony を学んでください。
* [Symfony The Fast Track][26] で Symfony エコシステムを詳しく発見してください。
* [ガイドとチュートリアル][8]、[コンポーネントドキュメント][9]、
  [ベストプラクティス][10]リファレンスで Symfony をマスターしてください。

コミュニティ
------------

* [Symfony コミュニティに参加][11]し、[Symfony イベント][12]で他のメンバーと会いましょう。
* GitHub Discussions、Slack などで [Symfony サポートを受ける][13]。
* [GitHub][14]、[Twitter][15]、[Facebook][16] で私たちをフォローしてください。
* [行動規範][24]を読み、[CARE チーム][25]と出会いましょう。

貢献
----

Symfony は数千人の[貢献者][19]を持つオープンソースの、コミュニティ主導のプロジェクトです。
[コードの貢献][17]または[ドキュメントの貢献][18]で彼らに参加してください。
